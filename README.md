# Smart Homework Assistant

ไฟล์โปรเจกต์สำหรับนำไปเผยแพร่เป็นเว็บไซต์/PWA

## ไฟล์ในโปรเจกต์
- `index.html` — แอปหลัก (HTML, CSS และ JavaScript)
- `manifest.json` — ข้อมูลสำหรับติดตั้งเป็นแอป
- `sw.js` — Service Worker สำหรับแคชไฟล์พื้นฐานและเปิดออฟไลน์
- `icon.svg` — ไอคอนแอป

## วิธีทดลอง
เปิด `index.html` ในเบราว์เซอร์เพื่อดูหน้าแอปได้ แต่การติดตั้ง PWA และ Service Worker ต้องเผยแพร่ผ่าน HTTPS (หรือ localhost)

## วิธีเผยแพร่
อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง GitHub repository แล้วนำ repository ไปเชื่อมกับ Vercel เพื่อ Deploy

## ข้อควรทราบเรื่องข้อมูล
ข้อมูลการบ้านใช้ Local Storage จึงอยู่ในเบราว์เซอร์และอุปกรณ์เครื่องนั้น ไม่ได้ซิงก์ข้ามอุปกรณ์หรือสำรองขึ้นคลาวด์ ควรหลีกเลี่ยงการล้างข้อมูลเว็บไซต์หากยังไม่ได้สำรองข้อมูล
